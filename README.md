# Site lokalapp.be

Copié tel quel dans le dépôt public `lokal-app-be/site` (GitHub Pages, gratuit).

- `index.html` : accueil.
- `404.html` : sert aussi les pages des QR codes `lokalapp.be/e/<numéro>` (GitHub Pages renvoie cette page pour toute adresse inconnue).
  Elle lit l'événement avec la clé publique de Supabase (la même que dans l'appli) : seuls les événements publics et visibles apparaissent.
- `CNAME` : le domaine.

Le site complet (lot 5) remplacera ces pages.
